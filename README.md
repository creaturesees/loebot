# Бот графіків відключень · Львів

Бот кожні кілька хвилин перевіряє графік погодинних відключень Львівобленерго.
Коли графік з'являється або змінюється, бот:

- малює табличку-картинку і надсилає її з текстом у Telegram (і в Discord, якщо налаштовано);
- пише внизу, що змінилося порівняно з попередньою версією;
- записує графік у `history.csv`, з якого будується сайт з календарем.

## Файли

| Файл | Що це |
|---|---|
| `loe_bot.py` | сам бот |
| `loe_image.py` | малює табличку-картинку |
| `index.html` | сайт з календарем і статистикою |
| `assets/` | шрифти (Carlito, Fira Sans), логотип, ліцензії шрифтів |
| `.github/workflows/loe.yml` | запуск бота в GitHub Actions |
| `last_hash.txt`, `last_schedules.json`, `history.csv` | стан і база, бот створює їх сам |

## Секрети

**Settings → Secrets and variables → Actions → New repository secret**

| Назва | Обов'язково | Значення |
|---|---|---|
| `BOT_TOKEN` | так | токен бота від @BotFather |
| `CHAT_ID` | так | id отримувачів через кому (`111,222`) або `@канал` |
| `DISCORD_WEBHOOK` | ні | URL вебхука Discord-каналу |
| `DISCORD_ROLE_ID` | ні | ID ролі, яку пінгувати в Discord |

## Сайт (GitHub Pages)

1. **Settings → Pages**
2. **Source:** Deploy from a branch
3. **Branch:** `main`, папка `/ (root)` → **Save**
4. Через 1–2 хвилини сайт буде на `https://<логін>.github.io/<назва-репозиторію>/`

Сайт сам підтягує `history.csv`, тому оновлюється після кожного нового графіка.

## Ручний запуск

**Actions → LOE schedule check → Run workflow.**

Щоб бот повторно надіслав поточний графік, видаліть `last_hash.txt` і запустіть вручну.
